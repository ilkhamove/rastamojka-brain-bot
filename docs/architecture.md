# Архитектура бота «Мозг таможни»

## 🎯 Цель проекта

Создать простой, надёжный и интуитивный Telegram-бот, который собирает данные по таможенному делу:
- документы (PDF, Word и т.д.),
- фотографии товаров и документов,
- голосовые сообщения (которые бот автоматически переводит в текст).

Все данные сохраняются в структурированную базу и будут использоваться позже в RAG-системе и LLM-боте, который сможет отвечать на вопросы, опираясь **строго на эту базу знаний**.

---

## 🧠 Основная идея

Это **бот-сборщик знаний**, не ИИ-ассистент.

Он:

1) принимает файл / фото / голосовое сообщение,  
2) спрашивает, к какому типу информации относится присланное,  
3) собирает короткое описание,  
4) сохраняет всё в базу в одном формате.

---

## 📥 Поддерживаемые входные данные

Бот принимает три типа:

### 1. Документ (`document`)
- PDF
- DOC / DOCX
- TXT
- изображения как файлы

### 2. Фото (`photo`)
- фото товаров
- фото документов

### 3. Голосовые (`voice`)
- бот отправляет на OpenAI API → получает транскрипт → сохраняет текст

---

## 🗂 Категории знаний (кнопки)

После получения файла/фото/голоса бот показывает категории:

- 🧾 **НПА (законы/постановления)**
- 📄 **Заключения / разъяснения**
- 📦 **Пояснения ТНВЭД**
- 🚛 **CMR / инвойс / СМГС / другое**
- 🧷 **Предварительное решение таможни**
- ⚖️ **Практика / кейсы**
- 🌀 **Другое**
- 🧠 **База**

Пользователь выбирает категорию, и запись формируется полностью.

---

## 👤 UX-сценарий (поток данных)

### 1. Пользователь нажимает /start  
Бот приветствует и говорит простое сообщение:

> «Пришлите файл, фото или голосовое сообщение, связанное с таможенным делом.»

*(Важно: никаких лишних кнопок. Дед 65 лет должен понять.)*

---

### 2. Пользователь отправляет медиа  
Бот:
- определяет тип (`document`, `photo`, `voice`)
- если голос → делает транскрипцию через OpenAI
- сохраняет всё во времённом контексте (FSM)

---

### 3. Бот показывает категории  
Пользователь выбирает одну из 8 кнопок.

---

### 4. Бот просит короткое текстовое описание  
Например:

> «Описание: письмо ГТК по электросамокатам»

Пользователь пишет текст → бот сохраняет.

---

### 5. Сохранение в базу  
Бот записывает:

- user  
- тип входа (файл/фото/голос)  
- telegram_file_id  
- транскрипт (если был voice)  
- выбранную категорию  
- описание  
- дату  

И отвечает:

> «✅ Запись сохранена в Мозг таможни.»

---

## 🧱 Структура данных (модель)

### User
- id  
- telegram_id  
- full_name  
- username  
- created_at  

### KnowledgeItem
- id  
- user_id (FK → User)  
- input_type (`document`, `photo`, `voice`)  
- telegram_file_id  
- transcript (если голос)  
- description  
- category  
- created_at  

### На будущее для RAG:
- combined_text  
- embedding_vector  
- source_meta

## 📡 Подготовка к RAG

База знаний будет использована для:

- извлечения текста из документов (OCR/парсинг),
- генерации эмбеддингов,
- контекстного поиска по базе,
- ответа ИИ-бота строго на основе ваших знаний.

Этот бот — фундамент всей системы Rastamojka AI.
