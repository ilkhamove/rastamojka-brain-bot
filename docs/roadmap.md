# Roadmap проекта «Мозг Таможни»

---

## Этап 1. MVP — Бот-сборщик знаний

### Цель:
Запустить бота, который принимает документы/фото/голосовые и сохраняет структуру знаний.

### Задачи:

1. 🔧 Инфраструктура
   - Настроить проект (GitHub, Cursor).
   - Создать структуру директорий.
   - Подготовить окружение (.env, requirements).
   - Подключить PostgreSQL.

2. 🤖 Telegram-бот
   - Простой сценарий:
     - /start
     - Приём файла, фото, голосового
     - Транскрипция через OpenAI
     - Выбор категории
     - Короткое описание
     - Сохранение в базу

3. 🗄 База данных
   - Таблица users
   - Таблица knowledge_items

4. ⚙FSM сценарий
   - состояние: ожидание медиа
   - состояние: ожидание категории
   - состояние: ожидание описания

---

## Этап 2. Подготовка данных для RAG

### Цель:
Сделать базу пригодной для дальнейшего использования LLM.

### Задачи:

- Нормализовать текст (описание + транскрипт)
- Добавить колонку combined_text
- Извлекать текст из документов (OCR/парсинг)
- Создать и хранить эмбеддинги
- Подготовить API поиска по базе

---

## Этап 3. RAG-бот / Mini App

### Цель:
ИИ-бот отвечает на вопросы по таможне, используя базу знаний.

### Задачи:

- Создать RAG-backend
- Создать Telegram Mini App или веб-чат
- Добавить возможность загрузки фото товара, документов
- Логика расчёта стоимости товара (по твоему промпту)
- Логика классификации ТНВЭД через RAG + правила ОПИ
